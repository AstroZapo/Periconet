Volver al panel principal

Añade un setup por cada telescopio/mini-PC de tu observatorio. Necesitas su nombre y las IPs donde corren NINA (Advanced API) y PHD2.

Entre 1024 y 65535. Por defecto 8000. Si lo cambias, reinicia Periconet y abre la nueva dirección (http://localhost:PUERTO).

Imágenes y páginas bajo los setups (opcional)

Deja la URL vacía para no mostrar ese hueco. «Imagen»: dirección directa de un JPG/PNG; la descarga Periconet desde este equipo, así que sirve también una URL accesible solo por VPN. «Página web completa»: muestra la página tal cual (por ejemplo la web de una cámara all-sky); la carga el navegador que mira el dashboard, así que ese navegador tiene que poder llegar a esa IP.

Techo Talon6 por Alpaca (opcional)

Con la dirección puesta, el panel del techo habla directamente con Talon6 aunque los NINA estén cerrados. Si Alpaca no responde, las órdenes pasan por el NINA que tenga la cúpula conectada. Déjala vacía para usar solo NINA.
